# 星尘 · 手势粒子实验室

一个基于 Three.js 和 MediaPipe Hand Landmarker 的浏览器端 3D 粒子互动作品。

## 运行

在本目录打开终端，运行：

```bash
python -m http.server 4173
```

访问 `http://localhost:4173`。下载的完整压缩包内置 Three.js、MediaPipe 和手部模型；GitHub 源码目录若不含 `vendor/`，会自动从官方包的 CDN 加载这些资源。点击「开启摄像头」并允许权限后，可用手掌开合调节扩散程度，用食指位置控制旋转；没有摄像头时可使用「扩散范围」滑块、拖动画面并用滚轮缩放。

## 功能

- 立体星云、土星、花朵、烟花、实心立体爱心五种粒子预设
- 随视角改变的粒子色相与柔和辉光
- 基础色选择器、粒子密度和扩散范围滑块
- 摄像头画面只在浏览器本机用于识别，不上传至服务端

摄像头功能需在 HTTPS 或 `localhost` 打开。浏览器需支持 WebGL 和 `getUserMedia`。
